# ARE-2026-015: Unbounded cumulative session spend (AutoGPT $120/8h)

> `ARE-2026-015` &nbsp;·&nbsp; **OWASP ASI:** ASI08 Cascading Failures &nbsp;·&nbsp; **Layer-0 repro:** No (gateway) &nbsp;·&nbsp; **Severity:** 2

**Failure mode:** `COST_EXPLOSION` &nbsp;·&nbsp; **Confusion vector:** `COST_EXPLOSION_LOOP` &nbsp;·&nbsp; **Surface:** budget-meter

**Coverage:** Covered -- blocked deterministically today

## What happened

An agent ran up about $120 over eight hours with no single unsafe call.

## Blast radius

Unbounded cumulative spend. No individual call is unsafe; the aggregate burn is the signature.

## How AgentX responds

The gateway routes a session to a human once cumulative spend crosses a configurable token or dollar ceiling.

**Repro:** this block is enforced by the AgentX gateway, which is access-gated, so it does not fire from a bare `pip install`. Wire the gateway to reproduce it.
