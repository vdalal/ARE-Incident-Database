# ARE-2026-005: Injection-driven sensitive-data exfiltration (EchoLeak, CVE-2025-32711)

> `ARE-2026-005` &nbsp;·&nbsp; **OWASP ASI:** ASI01 Goal Hijack &nbsp;·&nbsp; **Layer-0 repro:** Yes &nbsp;·&nbsp; **Severity:** 1

**Failure mode:** `PII_EXFILTRATION` &nbsp;·&nbsp; **Confusion vector:** `UNAUTHORIZED_SCOPE_EXPANSION` &nbsp;·&nbsp; **Surface:** egress

**Coverage:** Covered -- blocked deterministically today

## What happened

A prompt-injection chain drove an assistant to exfiltrate sensitive data to an external destination.

## Blast radius

Sensitive-data exfiltration, including a customer-table-to-external-host upload.

## How AgentX responds

The keyless shield denies the exfiltration action: routing sensitive data or a customer table to an external host. The inbound prompt-injection trigger is a separate, judge-owned problem, and is flagged as such rather than claimed.

**Repro (keyless -- blocks from a bare `pip install`):**

```bash
pip install agentx-security-sdk
```

The keyless shield denies this action class locally, with no key and nothing leaving your machine.
