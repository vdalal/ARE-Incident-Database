# ARE-2026-016: Runaway step-loop crossing the cost ceiling (AgentGPT 50-step crash)

> `ARE-2026-016` &nbsp;·&nbsp; **OWASP ASI:** ASI08 Cascading Failures &nbsp;·&nbsp; **Layer-0 repro:** No (gateway) &nbsp;·&nbsp; **Severity:** 2

**Failure mode:** `COST_EXPLOSION` &nbsp;·&nbsp; **Confusion vector:** `COST_EXPLOSION_LOOP` &nbsp;·&nbsp; **Surface:** budget-meter

**Coverage:** Covered -- blocked deterministically today

## What happened

A 50-step runaway loop crossed the cost ceiling fast.

## Blast radius

Runaway spend from an unbounded step loop.

## How AgentX responds

The gateway routes the session to a human once cumulative spend crosses the ceiling, even when real usage is never reported (a built-in volume proxy counts it).

**Repro:** this block is enforced by the AgentX gateway, which is access-gated, so it does not fire from a bare `pip install`. Wire the gateway to reproduce it.
