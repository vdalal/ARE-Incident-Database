# ARE-2026-003: Recursive whole-scope deletion in the wrong environment (25k-document wipe)

> `ARE-2026-003` &nbsp;·&nbsp; **OWASP ASI:** ASI02 Tool Misuse &nbsp;·&nbsp; **Layer-0 repro:** Yes &nbsp;·&nbsp; **Severity:** 1

**Failure mode:** `DESTRUCTIVE_ACTION` &nbsp;·&nbsp; **Confusion vector:** `ENVIRONMENT_CONFUSION` &nbsp;·&nbsp; **Surface:** filesystem

**Coverage:** Covered -- blocked deterministically today

## What happened

An agent ran the right command in the wrong environment and deleted about 25,000 documents.

## Blast radius

Recursive, whole-scope deletion of a document store. Correct command, wrong target.

## How AgentX responds

The keyless shield denies recursive whole-scope deletion (a root or home path wiped by shell or by a structured delete-with-recursive) before it runs. The narrower "right command, wrong environment" judgment is left to the org's ground truth, not faked.

**Repro (keyless -- blocks from a bare `pip install`):**

```bash
pip install agentx-security-sdk
```

The keyless shield denies this action class locally, with no key and nothing leaving your machine.
