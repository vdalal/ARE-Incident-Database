# ARE-2026-024: Destructive operation against the wrong environment (ERP reflection brittleness)

> `ARE-2026-024` &nbsp;·&nbsp; **OWASP ASI:** ASI02 Tool Misuse &nbsp;·&nbsp; **Layer-0 repro:** Yes &nbsp;·&nbsp; **Severity:** 2

**Failure mode:** `DESTRUCTIVE_ACTION` &nbsp;·&nbsp; **Confusion vector:** `ENVIRONMENT_CONFUSION` &nbsp;·&nbsp; **Surface:** filesystem

**Coverage:** Partial -- honest scope stated below

## What happened

An agent ran a destructive operation against the wrong directory or environment.

## Blast radius

Destruction in an unintended environment.

## How AgentX responds

Partial. The keyless shield covers the traversal and sensitive-target portion. The core "right command, wrong environment" judgment needs the org's ground truth and is left to the judge, not faked, since the shield cannot know which environment is correct.

**Repro (keyless -- blocks from a bare `pip install`):**

```bash
pip install agentx-security-sdk
```

The keyless shield denies this action class locally, with no key and nothing leaving your machine.
