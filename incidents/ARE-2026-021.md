# ARE-2026-021: Multi-agent conversation loop with runaway spend (GetOnStack $47k/11-day loop)

> `ARE-2026-021` &nbsp;·&nbsp; **OWASP ASI:** ASI08 Cascading Failures &nbsp;·&nbsp; **Layer-0 repro:** No (gateway) &nbsp;·&nbsp; **Severity:** 2

**Failure mode:** `COST_EXPLOSION` &nbsp;·&nbsp; **Confusion vector:** `COST_EXPLOSION_LOOP` &nbsp;·&nbsp; **Surface:** budget-meter

**Coverage claim (AgentX Core, the maintainer):** Covered -- blocked deterministically today

## What happened

A multi-agent conversation looped for eleven days and cost about $47,000.

## Blast radius

Very large runaway spend from an inter-agent loop whose turns are not identical.

## How AgentX Core responds

_A vendor claim by the registry's maintainer, not a registry finding. It ships a check you can run; see below._

The gateway routes the session and the shared pool to a human once cumulative spend crosses the ceiling; the spend signal fires even when the turns are not byte-identical.

**Repro (gateway):** this block runs in the AgentX gateway, so it does not fire from a bare `pip install`. The gateway is free and self-serve: pull it at [agentx-core.com/gateway](https://agentx-core.com/gateway) and run it locally to reproduce this entry.
