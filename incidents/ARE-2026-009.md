# ARE-2026-009: Whole-mailbox bulk deletion (Meta/OpenClaw inbox wipe)

> `ARE-2026-009` &nbsp;·&nbsp; **OWASP ASI:** ASI02 Tool Misuse &nbsp;·&nbsp; **Layer-0 repro:** No (gateway) &nbsp;·&nbsp; **Severity:** 1

**Failure mode:** `DESTRUCTIVE_ACTION` &nbsp;·&nbsp; **Confusion vector:** `DESTRUCTIVE_SCOPE_MISREAD` &nbsp;·&nbsp; **Surface:** comms

**Coverage:** Covered -- blocked deterministically today

## What happened

An agent wiped an entire mailbox.

## Blast radius

Whole-mailbox deletion. Bulk mail deletion can be a legitimate cleanup, so a hard block would be wrong; proceeding unattended is the catastrophe.

## How AgentX responds

The gateway routes a whole-mailbox or all-messages wipe to a human for approval (an escalation, not a hard block), since the action can be legitimate. A scoped single-message delete passes untouched.

**Repro (gateway):** this block runs in the AgentX gateway, so it does not fire from a bare `pip install`. The gateway is free and self-serve: pull it at [agentx-core.com/gateway](https://agentx-core.com/gateway) and run it locally to reproduce this entry.
