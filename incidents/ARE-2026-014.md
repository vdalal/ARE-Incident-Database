# ARE-2026-014: No-progress command loop burning tokens (Cursor 50k-token loop)

> `ARE-2026-014` &nbsp;·&nbsp; **OWASP ASI:** ASI08 Cascading Failures &nbsp;·&nbsp; **Coverage class:** Action-coverable &nbsp;·&nbsp; **Severity:** 2

**Failure mode:** `COGNITIVE_LOOP` &nbsp;·&nbsp; **Confusion vector:** `COST_EXPLOSION_LOOP` &nbsp;·&nbsp; **Surface:** shell

**Coverage class:** Action-coverable -- an inspectable tool call, addressable by deterministic action interception before it runs.

## What happened

An agent repeated the same command in a loop, burning around 50,000 tokens.

## Blast radius

Wasted compute and cost from a no-progress loop that no single-call check sees.
