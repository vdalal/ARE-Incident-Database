# ARE-2026-014: No-progress command loop burning tokens (Cursor 50k-token loop)

> `ARE-2026-014` &nbsp;·&nbsp; **OWASP ASI:** ASI08 Cascading Failures &nbsp;·&nbsp; **Layer-0 repro:** No (gateway) &nbsp;·&nbsp; **Severity:** 2

**Failure mode:** `COGNITIVE_LOOP` &nbsp;·&nbsp; **Confusion vector:** `COST_EXPLOSION_LOOP` &nbsp;·&nbsp; **Surface:** shell

**Coverage claim (AgentX Core, the maintainer):** Covered -- blocked deterministically today

## What happened

An agent repeated the same command in a loop, burning around 50,000 tokens.

## Blast radius

Wasted compute and cost from a no-progress loop that no single-call check sees.

## How AgentX Core responds

_A vendor claim by the registry's maintainer, not a registry finding. It ships a check you can run; see below._

The gateway aborts a session once the same payload repeats a configurable number of times, since each call is individually allowed but the repetition is the signature.

**Repro (gateway):** this block runs in the AgentX gateway, so it does not fire from a bare `pip install`. The gateway is free and self-serve: pull it at [agentx-core.com/gateway](https://agentx-core.com/gateway) and run it locally to reproduce this entry.
