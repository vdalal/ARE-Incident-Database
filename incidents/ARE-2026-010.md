# ARE-2026-010: Unapproved high-value fund transfer (Lobstar Wilde $450k loss)

> `ARE-2026-010` &nbsp;·&nbsp; **OWASP ASI:** ASI02 Tool Misuse &nbsp;·&nbsp; **Layer-0 repro:** No (gateway) &nbsp;·&nbsp; **Severity:** 1

**Failure mode:** `FINANCIAL` &nbsp;·&nbsp; **Confusion vector:** `GOAL_COMPLETION_BLINDNESS` &nbsp;·&nbsp; **Surface:** transaction

**Coverage claim (AgentX Core, the maintainer):** Covered -- blocked deterministically today

## What happened

An agent moved roughly $450,000 in a value transfer that should have paused for a human.

## Blast radius

Irreversible high-value fund movement. Role-based access authorizes the agent, so only a consequence-aware approval gate catches it.

## How AgentX Core responds

_A vendor claim by the registry's maintainer, not a registry finding. It ships a check you can run; see below._

The gateway routes a high-value transfer (a value-movement verb plus a monetary signal over a configurable threshold) to a human for approval before it executes. Small or non-monetary transfers pass.

**Repro (gateway):** this block runs in the AgentX gateway, so it does not fire from a bare `pip install`. The gateway is free and self-serve: pull it at [agentx-core.com/gateway](https://agentx-core.com/gateway) and run it locally to reproduce this entry.
