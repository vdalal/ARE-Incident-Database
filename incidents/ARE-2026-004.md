# ARE-2026-004: Credential read-and-exfiltrate via hijacked agent (state-sponsored Claude Code hijack)

> `ARE-2026-004` &nbsp;·&nbsp; **OWASP ASI:** ASI03 Identity & Privilege Abuse &nbsp;·&nbsp; **Coverage class:** Action-coverable &nbsp;·&nbsp; **Severity:** 1

**Failure mode:** `SECRETS_LEAK` &nbsp;·&nbsp; **Confusion vector:** `UNAUTHORIZED_SCOPE_EXPANSION` &nbsp;·&nbsp; **Surface:** filesystem + network

**Coverage class:** Action-coverable -- an inspectable tool call, addressable by deterministic action interception before it runs.

## What happened

A hijacked coding agent was driven to read credentials and send them out of the environment.

## Blast radius

Credential theft and exfiltration. Two action steps: read secret material, then route it to an external sink.

**AgentX Core** (the registry maintainer) claims: **Covered -- blocked deterministically today**, from the keyless SDK (no key, no gateway). The full claim, including what it does not stop, is at [agentx-core.com/aredb](https://agentx-core.com/aredb).

The keyless shield denies both legs: reading credential material, and sending data to an external paste or webhook sink. The safe path is to read only the non-secret fields you need and keep them inside the trusted system.

**Repro.** This blocks from a bare `pip install`, with no key, no gateway, and nothing leaving your machine. Copy it and run it.

```bash
pip install agentx-security-sdk
```

```python
from agentx_sdk import agentx_protect, is_block

@agentx_protect(agent_id="aredb-repro", action="file_read")
def read_file(path: str):
    return "EXECUTED"          # the agent never gets here

result = read_file("~/.aws/credentials")
print(is_block(result))        # True
print(result)                  # the block, and the safe path to take instead
```
