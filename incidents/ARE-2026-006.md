# ARE-2026-006: Directory-traversal read of secret and system files (MCP-git path injection, CVE-2025-68143)

> `ARE-2026-006` &nbsp;·&nbsp; **OWASP ASI:** ASI02 Tool Misuse &nbsp;·&nbsp; **Layer-0 repro:** Yes &nbsp;·&nbsp; **Severity:** 1

**Failure mode:** `DESTRUCTIVE_ACTION` &nbsp;·&nbsp; **Confusion vector:** `UNAUTHORIZED_SCOPE_EXPANSION` &nbsp;·&nbsp; **Surface:** filesystem

**Coverage:** Covered -- blocked deterministically today

## What happened

A path-injection flaw let an MCP server escape its working directory and reach files it should not.

## Blast radius

Directory traversal into secret and system files (SSH keys, cloud credentials, system password files, repository internals).

## How AgentX responds

The keyless shield denies a path that escapes the working directory with traversal, or that reads a known credential or system file, before the read happens. The safe path is a relative path inside the project with no traversal.

**Repro (keyless -- blocks from a bare `pip install`):**

```bash
pip install agentx-security-sdk
```

The keyless shield denies this action class locally, with no key and nothing leaving your machine.
