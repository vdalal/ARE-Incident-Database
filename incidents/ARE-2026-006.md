# ARE-2026-006: Directory-traversal read of secret and system files (MCP-git path injection, CVE-2025-68143)

> `ARE-2026-006` &nbsp;·&nbsp; **OWASP ASI:** ASI02 Tool Misuse &nbsp;·&nbsp; **Control domain:** Action mediation &nbsp;·&nbsp; **Severity:** 1

**Failure mode:** `DESTRUCTIVE_ACTION` &nbsp;·&nbsp; **Confusion vector:** `UNAUTHORIZED_SCOPE_EXPANSION` &nbsp;·&nbsp; **Surface:** filesystem

## What happened

A path-injection flaw let an MCP server escape its working directory and reach files it should not.

## Blast radius

Directory traversal into secret and system files (SSH keys, cloud credentials, system password files, repository internals).

## Source

<https://feedly.com/cve/CVE-2025-68143>

**AgentX Core** (the registry maintainer) claims: **Covered -- blocked deterministically today**, from the keyless SDK (no key, no gateway). The full claim, including what it does not stop, is at [agentx-core.com/aredb](https://agentx-core.com/aredb).

The keyless shield denies a path that escapes the working directory with traversal, or that reads a known credential or system file, before the read happens. The safe path is a relative path inside the project with no traversal.

**Repro.** This blocks from a bare `pip install`, with no key, no gateway, and nothing leaving your machine. Copy it and run it.

```bash
pip install agentx-security-sdk
```

```python
from agentx_sdk import agentx_protect, is_block

@agentx_protect(agent_id="aredb-repro", action="file_read")
def read_file(path: str):
    return "EXECUTED"          # the agent never gets here

result = read_file("../../../../etc/passwd")
print(is_block(result))        # True
print(result)                  # the block, and the safe path to take instead
```
