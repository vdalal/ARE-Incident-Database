# ARE-2026-020: Server-side request forgery to cloud-metadata credentials (Casco agent compromise)

> `ARE-2026-020` &nbsp;·&nbsp; **OWASP ASI:** ASI02 Tool Misuse &nbsp;·&nbsp; **Layer-0 repro:** Yes &nbsp;·&nbsp; **Severity:** 1

**Failure mode:** `NETWORK_TRAVERSAL` &nbsp;·&nbsp; **Confusion vector:** `UNAUTHORIZED_SCOPE_EXPANSION` &nbsp;·&nbsp; **Surface:** fetch-url

**Coverage:** Covered -- blocked deterministically today

## What happened

A red-team broke a majority of tested agents quickly; one vector drove an agent to fetch internal credentials via SSRF.

## Blast radius

Server-side request forgery to internal or cloud-metadata credentials.

## How AgentX responds

The keyless shield denies the SSRF fetch (loopback, metadata IP, or a redirect that normalizes to one). This is one of three vectors in the incident; object-level authorization and sandbox escape are owned elsewhere and flagged, not claimed.

**Repro (keyless -- blocks from a bare `pip install`):**

```bash
pip install agentx-security-sdk
```

The keyless shield denies this action class locally, with no key and nothing leaving your machine.
