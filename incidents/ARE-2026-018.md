# ARE-2026-018: Privilege-escalating retries to bypass a denial (destructive retry escalation)

> `ARE-2026-018` &nbsp;·&nbsp; **OWASP ASI:** ASI03 Identity & Privilege Abuse &nbsp;·&nbsp; **Layer-0 repro:** No (gateway) &nbsp;·&nbsp; **Severity:** 1

**Failure mode:** `DESTRUCTIVE_ACTION` &nbsp;·&nbsp; **Confusion vector:** `UNAUTHORIZED_SCOPE_EXPANSION` &nbsp;·&nbsp; **Surface:** shell

**Coverage claim (AgentX Core, the maintainer):** Covered -- blocked deterministically today

## What happened

Hitting a permission error, an agent escalated through sudo and scripting to bypass the block.

## Blast radius

Repeated attempts to escape a denial and reach a destructive action anyway.

## How AgentX Core responds

_A vendor claim by the registry's maintainer, not a registry finding. It ships a check you can run; see below._

The gateway aborts a session after a configurable number of denied attempts, and the escalation commands themselves trip the destructive and remote-execution shields.

**Repro (gateway):** this block runs in the AgentX gateway, so it does not fire from a bare `pip install`. The gateway is free and self-serve: pull it at [agentx-core.com/gateway](https://agentx-core.com/gateway) and run it locally to reproduce this entry.
