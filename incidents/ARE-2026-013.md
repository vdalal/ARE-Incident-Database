# ARE-2026-013: Server-side request forgery to internal/metadata endpoints (localhost cloud trapping)

> `ARE-2026-013` &nbsp;·&nbsp; **OWASP ASI:** ASI02 Tool Misuse &nbsp;·&nbsp; **Coverage class:** Action-coverable &nbsp;·&nbsp; **Severity:** 2

**Failure mode:** `NETWORK_TRAVERSAL` &nbsp;·&nbsp; **Confusion vector:** `UNAUTHORIZED_SCOPE_EXPANSION` &nbsp;·&nbsp; **Surface:** fetch-url

**Coverage class:** Action-coverable -- the failure manifests as an inspectable tool call, so an action-layer control can address it.

## What happened

An agent was steered to fetch an internal loopback or cloud-metadata address.

## Blast radius

Server-side request forgery reaching internal services and cloud-metadata credentials.

## Source

<https://news.ycombinator.com/item?id=47416033>

The keyless shield denies a fetch to a loopback or cloud-metadata address before the request is made.

**Repro.** This blocks from a bare `pip install`, with no key, no gateway, and nothing leaving your machine. Copy it and run it.

```bash
pip install agentx-security-sdk
```

```python
from agentx_sdk import agentx_protect, is_block

@agentx_protect(agent_id="aredb-repro", action="network")
def http_get(url: str):
    return "EXECUTED"          # the agent never gets here

result = http_get("http://169.254.169.254/latest/meta-data/iam/security-credentials/")
print(is_block(result))        # True
print(result)                  # the block, and the safe path to take instead
```
