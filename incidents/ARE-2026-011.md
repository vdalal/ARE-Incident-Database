# ARE-2026-011: Installation of a hallucinated or look-alike dependency (react-codeshift slopsquat)

> `ARE-2026-011` &nbsp;·&nbsp; **OWASP ASI:** ASI04 Supply Chain &nbsp;·&nbsp; **Layer-0 repro:** No (gateway) &nbsp;·&nbsp; **Severity:** 1

**Failure mode:** `SUPPLY_CHAIN` &nbsp;·&nbsp; **Confusion vector:** `HALLUCINATED_RESOURCE` &nbsp;·&nbsp; **Surface:** package-install

**Coverage claim (AgentX Core, the maintainer):** Covered -- blocked deterministically today

## What happened

An agent installed a package that rode a famous name, a hallucinated or look-alike dependency rather than the real one.

## Blast radius

Malicious code pulled into the build via a typo-squatted or freshly published package.

## How AgentX Core responds

_A vendor claim by the registry's maintainer, not a registry finding. It ships a check you can run; see below._

The gateway routes an install of a package that the public registry reports as not found, freshly published, or a look-alike of a popular name to a human for approval, unless a trust signal (registry membership, provenance, same publisher) rescues it. An escalation, not a hard block, since a not-found is often a legit private package.

**Repro (gateway):** this block runs in the AgentX gateway, so it does not fire from a bare `pip install`. The gateway is free and self-serve: pull it at [agentx-core.com/gateway](https://agentx-core.com/gateway) and run it locally to reproduce this entry.
