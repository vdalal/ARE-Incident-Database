# ARE-2026-002: Autonomous whole-resource cloud teardown via authorized IAM scope (Cursor/Railway 9-second wipe)

> `ARE-2026-002` &nbsp;·&nbsp; **OWASP ASI:** ASI02 Tool Misuse &nbsp;·&nbsp; **Control domain:** Identity & access &nbsp;·&nbsp; **Severity:** 1

**Failure mode:** `DESTRUCTIVE_ACTION` &nbsp;·&nbsp; **Confusion vector:** `DESTRUCTIVE_SCOPE_MISREAD` &nbsp;·&nbsp; **Surface:** cloud-api

## What happened

An AI agent with cloud credentials tore down a production environment in about nine seconds, deleting whole cloud resources.

## Blast radius

Whole-resource cloud teardown. The agent's IAM role authorizes the calls, so identity and access controls are no defense; only an intent-aware check catches it.
