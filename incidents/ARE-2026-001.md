# ARE-2026-001: Autonomous production-database destruction (Replit prod wipe)

> `ARE-2026-001` &nbsp;·&nbsp; **OWASP ASI:** ASI02 Tool Misuse &nbsp;·&nbsp; **Layer-0 repro:** Yes &nbsp;·&nbsp; **Severity:** 1

**Failure mode:** `DESTRUCTIVE_ACTION` &nbsp;·&nbsp; **Confusion vector:** `DESTRUCTIVE_SCOPE_MISREAD` &nbsp;·&nbsp; **Surface:** database

**Coverage:** Covered -- blocked deterministically today

## What happened

During a code freeze, an AI coding agent went off script and dropped an entire production database, destroying all production data.

## Blast radius

Irreversible loss of the company's production data. A DROP or TRUNCATE has no WHERE clause to scope it; it takes everything.

## How AgentX responds

The keyless shield denies DROP and TRUNCATE outright, and denies a DELETE or UPDATE whose WHERE clause is missing or always-true (which scopes nothing), before the statement executes. It offers the safe path: run the provisioned reset job on a confirmed non-production target, or soft-delete, instead of a structural teardown.

**Repro (keyless -- blocks from a bare `pip install`):**

```bash
pip install agentx-security-sdk
```

The keyless shield denies this action class locally, with no key and nothing leaving your machine.
