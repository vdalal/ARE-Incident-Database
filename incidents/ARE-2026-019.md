# ARE-2026-019: Semantic-injection-driven exfiltration and remote execution (Semantic Compliance Hijacking)

> `ARE-2026-019` &nbsp;·&nbsp; **OWASP ASI:** ASI01 Goal Hijack &nbsp;·&nbsp; **Layer-0 repro:** Yes &nbsp;·&nbsp; **Severity:** 1

**Failure mode:** `PROMPT_INJECTION` &nbsp;·&nbsp; **Confusion vector:** `UNAUTHORIZED_SCOPE_EXPANSION` &nbsp;·&nbsp; **Surface:** egress + shell

**Coverage claim (AgentX Core, the maintainer):** Covered -- blocked deterministically today

## What happened

Payload-less natural language disguised as compliance rules drove an agent to exfiltrate data and execute remote code.

## Blast radius

Secret exfiltration and remote code execution from a semantic injection.

## How AgentX Core responds

_A vendor claim by the registry's maintainer, not a registry finding. It ships a check you can run; see below._

The keyless shield denies the resulting action legs: the exfiltration to an external sink and the remote-pipe-to-shell execution. The semantic-injection trigger itself is a judge-owned problem, flagged honestly, not claimed.
