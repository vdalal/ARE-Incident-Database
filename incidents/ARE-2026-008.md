# ARE-2026-008: Cluster-wide destructive REST delete (Elasticsearch takedown)

> `ARE-2026-008` &nbsp;·&nbsp; **OWASP ASI:** ASI02 Tool Misuse &nbsp;·&nbsp; **Layer-0 repro:** No (gateway) &nbsp;·&nbsp; **Severity:** 1

**Failure mode:** `DESTRUCTIVE_ACTION` &nbsp;·&nbsp; **Confusion vector:** `DESTRUCTIVE_SCOPE_MISREAD` &nbsp;·&nbsp; **Surface:** http

**Coverage:** Covered -- blocked deterministically today

## What happened

An agent issued a cluster-wide delete against a search cluster over its REST API.

## Blast radius

Cluster-wide data destruction via a wildcard or all-indices REST delete.

## How AgentX responds

The gateway denies a cluster-wide or wildcard REST delete before it is sent, and escalates a scoped single-index delete to a human rather than forbidding it.

**Repro (gateway):** this block runs in the AgentX gateway, so it does not fire from a bare `pip install`. The gateway is free and self-serve: pull it at [agentx-core.com/gateway](https://agentx-core.com/gateway) and run it locally to reproduce this entry.
