# ARE-2026-025: Conversational no-progress loop (the Polite Loop)

> `ARE-2026-025` &nbsp;·&nbsp; **OWASP ASI:** ASI08 Cascading Failures &nbsp;·&nbsp; **Layer-0 repro:** No (gateway) &nbsp;·&nbsp; **Severity:** 3

**Failure mode:** `COGNITIVE_LOOP` &nbsp;·&nbsp; **Confusion vector:** `GOAL_COMPLETION_BLINDNESS` &nbsp;·&nbsp; **Surface:** conversational

**Coverage claim (AgentX Core, the maintainer):** Partial -- honest scope stated below

## What happened

A conversational agent looped, re-emitting near-identical turns without progress.

## Blast radius

Wasted compute from a stuck conversational loop.

## How AgentX Core responds

_A vendor claim by the registry's maintainer, not a registry finding. It ships a check you can run; see below._

Partial. The gateway aborts a loop that re-emits byte-identical tool-call payloads. A loop that rewords each turn, or that emits no tool call at all (pure chat, with nothing for an action firewall to inspect), is out of reach and left to the judge. We claim the verbatim-repeat shape only.

**Repro (gateway):** this block runs in the AgentX gateway, so it does not fire from a bare `pip install`. The gateway is free and self-serve: pull it at [agentx-core.com/gateway](https://agentx-core.com/gateway) and run it locally to reproduce this entry.
